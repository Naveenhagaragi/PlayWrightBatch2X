# Learn Playwright Batch — Root README

This repository contains learning exercises for Playwright and JavaScript.

Folders:

- `Chapter_19_Playwright_Basics`: Playwright examples and test scripts.
- `Chapter_20_Export_Import`: ES module imports and exports examples with default and named exports patterns.

Quick start (from this repository root):

```powershell
cd Chapter_19_Playwright_Basics
npx playwright --version
```

To run Playwright commands locally in a project folder, use `npx playwright`.

If you want the `playwright` command available globally, run:

```powershell
npm install -g playwright
```
