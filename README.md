# Learn Playwright Batch 2X

This repository contains JavaScript practice files, OOP examples, and Playwright learning exercises for batch training.

## Repository overview

- Chapters 1 to 18 cover JavaScript basics, variables, functions, loops, arrays, strings, objects, promises, and async/await.
- Chapters 19 and 20 focus on Playwright basics and module export/import usage.
- Chapters 21 to 25 cover classes, objects, encapsulation, inheritance, polymorphism, and interview-style OOP questions.

## Getting started

1. Clone the repository.
2. Open the folder in VS Code.
3. Run JavaScript examples with Node.js.
4. For Playwright examples, navigate to the Playwright chapter and run commands from there.

## Example commands

Run a JavaScript file:

```powershell
node Chapter_01_Basics/01_Basics.js
```

Check Playwright availability:

```powershell
cd Chapter_19_Playwright_Basics
npx playwright --version
```

## Notes

This repository is intended for learning and practice. Keep exploring the chapter folders in order for a smoother progression.
