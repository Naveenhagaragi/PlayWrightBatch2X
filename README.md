# Learn Playwright Batch 2X

This repository contains JavaScript, TypeScript, object-oriented programming, and Playwright learning examples for batch training.

## Repository overview

- Chapters 1 to 18 cover JavaScript fundamentals such as variables, functions, loops, arrays, strings, objects, promises, and async/await.
- Chapters 19 and 20 focus on Playwright basics and module export/import usage.
- Chapters 21 to 25 cover classes, objects, encapsulation, inheritance, polymorphism, and interview-style OOP questions.
- Chapters 27 onward include TypeScript interface, enum, generics, access modifiers, and override/decorator topics.

## Getting started

1. Clone the repository.
2. Open the project folder in VS Code.
3. Run JavaScript or TypeScript examples with Node.js or the TypeScript compiler as needed.
4. For Playwright examples, open the relevant chapter folder and run commands from there.

## Example commands

Run a JavaScript file:

```powershell
node chapter_01_Basics/01_Basics.js
```

Check Playwright availability:

```powershell
cd Chapter_19_Playwright_Basics
npx playwright --version
```

## Notes

This repository is intended for learning and practice. Explore the chapter folders in order for a smoother progression from basics to advanced topics.
